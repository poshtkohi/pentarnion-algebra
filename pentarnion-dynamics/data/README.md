# Exact-model sample data

These tables and summaries are generated by the supplied scientific programs;
they are not digitised from the manuscript figures. The full-resolution NPZ
records and regenerated plots are produced by the same programs when run.

| Directory | Generator | Contents |
| --- | --- | --- |
| `rank_four_riccati/` | `code/rank_four_riccati_theory.py` | The nonlinear elliptic orbit and its invariant, quadrature and return-error summary |
| `elliptic_flow/` | `code/generate_exact_models.py` | The full-dimensional Jacobi solution, its sampled components and residual summary |
| `appendix_associator_235/` | `code/generate_exact_models.py` | The compensated 2:3:5 solution, the eta=0.9 comparison, and the return-defect summary |
| `bracketing_flow/` | `code/check_reported_periodic_orbit.py` | A reintegration of the manuscript's reported phase point and period, including closure and Floquet information |

Column names in the CSV headers specify the coordinates. In the full-dimensional
and 2:3:5 models, `(w,x,y,z,u)` are coefficients in the canonical basis
`(1,i,j,k,ell)`. The rank-four table uses the reduced variables given in its header.
Time is the independent variable used in the manuscript; no physical unit is imposed.

The NPZ files expected by the complete bracketing-flow plotting and audit
programs are distinct numerical records. Consult
[the computational guide](../docs/reproducibility.md#reference-record-workflows)
for their input requirements. The endpoint checker and continuation program
can run independently of those plotting records.
