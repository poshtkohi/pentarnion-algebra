# Riccati symbolic verification and validation plots

## Plotting supplied numerical results

`make_validation_figures.py` reads the results already supplied in
`data/riccati/section9_validation/` and the periodic-branch tables. It generates
five local diagnostic plots. It does not need the original validation drivers,
which are not present in this distribution.

Run from `quaternions-to-pentarnions/`:

```bash
python code/06_riccati_dynamics/section9_validation/make_validation_figures.py
```

Outputs go to `outputs/plots/`, or the directory in `PENTARNION_OUTPUT_DIR`.
For the distinction between data inspection and rerunning the calculations,
see `docs/reproducibility.md` in `quaternions-to-pentarnions/`.

## Exact characteristic-polynomial verification

Run from `quaternions-to-pentarnions/`:

```bash
python code/06_riccati_dynamics/section9_validation/verify_characteristic_polynomial.py
```

This standalone script requires only Python 3.10+ and SymPy (already listed in
`requirements.txt`). It does not read numerical data, use the missing validation
drivers, or run a simulation. It is also included in both modes of the repository's
`run_full_verification.py` workflow.

### Identity and construction

The canonical basis is `(1,i,j,k,ell)`. The coefficient is
`A_gamma=(-1/2,-2,1/2,-1,-gamma/2)`; the fifth entry is already the actual
coefficient of `ell` and must not be multiplied by gamma a second time.

The script builds `L_A_gamma` by applying the stated bilinear multiplication to
all five basis vectors. It also constructs the displayed Appendix A matrix and
checks that the two general matrix formulas agree in every entry. It computes
`det(lambda I_5 - L_A_gamma)` with SymPy's characteristic-polynomial routine and
checks all six coefficients against

```text
(lambda^2 + lambda + (22+gamma^2)/4)
  * (lambda^3 + (3/2)*lambda^2 + b_gamma*lambda + c_gamma),

b_gamma = 3*(16+gamma^2-gamma^4)/(8*(1+gamma^2)),
c_gamma = (44-gamma^2-3*gamma^4
           + sqrt(2)*gamma*(gamma^4+gamma^2+194))/(16*(1+gamma^2)).
```

All arithmetic is exact. To avoid manipulating nested radicals, the computation
uses `sigma=gamma*kappa` and reduces polynomials in `kappa` modulo
`(1+gamma^2)*kappa^2-1`, over the rational-function field `Q(sqrt(2))(gamma)`.
The intended branch is `kappa=1/sqrt(1+gamma^2)`. Because `1+gamma^2` is nonzero
for real gamma, this calculation covers all real gamma, including the complete
manuscript interval `[0,1]`. It does not infer an identity from sampled values.

Any nonzero matrix or polynomial residual causes a nonzero exit status. Failure
checks are explicit exceptions and remain active under `python -O`.

### Output

The default result is written to
`outputs/riccati_validation/characteristic_polynomial_checks.txt`. It records the
matrix, factors, computed coefficients, exact zero residuals and Python/SymPy
versions. Change the destination with `--output DIR`.

A [reference report](symbolic/characteristic_polynomial_checks.txt) generated by
a successful run is included for inspection. The verifier does not read or trust
that report; it recomputes the identities each time. Normal runs leave both this
reference file and all supplied numerical data unchanged.

This verifies the factorisation labelled `eq:riccati-characteristic` with
coefficients `eq:riccati-bc`. It does **not** recompute the first Lyapunov
coefficient, periodic orbits, continuation branches or finite-time exponents.
The original numerical drivers described in the reproduction guide remain
separate and are not supplied by this addition.
