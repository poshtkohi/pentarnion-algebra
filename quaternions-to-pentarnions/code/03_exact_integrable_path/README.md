# Elliptic solutions and exact algebraic identities

From `quaternions-to-pentarnions/`:

```bash
python code/03_exact_integrable_path/symbolic_verification.py
python code/03_exact_integrable_path/verify_ordered_product_representation.py
python code/03_exact_integrable_path/generate_figures_and_data.py
```

The first verifies invariant-ideal identities. The second solves and verifies
the ordered-product coefficient system using rational-function arithmetic.
The third generates the specified elliptic trajectories and numerical residuals.
New results go beneath `outputs/exact_integrable/`; supplied expressions and
`data/exact_integrable/` remain unchanged. `run_all.py` runs all three programs.
